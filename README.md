# 🛒 Amazon Clone Website (HTML & CSS3)

This is a front-end clone of the Amazon homepage built using **HTML5** and **CSS3**. The project focuses on replicating the look and feel of Amazon’s main landing page to help beginners practice layout, positioning, and responsive design using only HTML and CSS.

---

## 📌 Key Features

- Amazon-style navigation bar with logo, search bar, and cart
- Product section with multiple categories and hover effects
- Simple responsive design for different screen sizes
- Footer with multi-column layout and links
- Pure HTML and CSS (no JavaScript or frameworks used)

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- [Font Awesome](https://fontawesome.com/) (optional icons)
- [Google Fonts](https://fonts.google.com/) (for custom fonts)
